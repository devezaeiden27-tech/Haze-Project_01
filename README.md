# HAZE

A compact Godot 4 third-person combat prototype.

Open this folder in Godot 4 and run `scenes/main.tscn`. Desktop controls: WASD to move, Shift to sprint, Space to dodge, and left mouse button to attack. Android builds show an on-screen movement stick and combat buttons.

The arena contains four enemies. Sword hits use an active 3D physics hitbox; dodging grants a brief invulnerability window. On death, press Enter or tap the screen to restart.
